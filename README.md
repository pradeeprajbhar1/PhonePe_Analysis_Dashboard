# 📊 PhonePe_Analysis_Dashboard

An interactive Power BI dashboard built to analyze PhonePe transaction data. This dashboard provides valuable insights into transactions, users, payment success rate, and service-wise performance using interactive visualizations.

---

## 📌 Project Overview

The PhonePe Analysis Dashboard helps users understand transaction trends, user engagement, payment performance, and service usage. It includes interactive filters and dynamic visualizations for better business insights.

---

## ✨ Dashboard Features

- 📈 Total Transactions (300K)
- 💰 Total Transaction Value (₹3 Billion)
- 👥 Unique Users (108K)
- ✅ Payment Success Rate (96%)
- 📅 Monthly Transaction Trend Analysis
- 👨‍👩‍👧 Age Segment Contribution
- 💳 Service Transaction Value Analysis
- 🏆 Top 5 Users by Transaction Value
- 📆 Weekday vs Weekend Usage Analysis
- 🎛️ Interactive Filters (Month & Payment Status)

## 📊 Key Insights

- Processed over **300K transactions**.
- Total transaction value reached **₹3 Billion**.
- Payment success rate remained **96%**.
- Gen X and Millennials contributed the highest share of users.
- Loan services generated the highest transaction value.
- Weekend transactions were higher than weekday transactions.
